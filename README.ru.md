# Капри — живая

Капри, конструкт *Project Capricorn* из Cyberpunk: Edgerunners (2 сезон), живёт у тебя на рабочем столе. Она следит
за твоим ИИ для кода (Claude Code, Codex, Antigravity), болтает с тобой через локальную или облачную нейросеть —
**Claude**, Ollama, Gemini, GPT и другие, — злится, смеётся, обижается и смущается, говорит голосом, меняет цвет, видит
твой экран, слышит тебя, двигается под твою музыку, запоминает, кто ты, и живёт своей жизнью, пока ты занят.

> Это фанатский проект. Ответы пишет ИИ, а не сценаристы сериала, — это фанатская версия персонажа.

## Быстрый старт

1. **Установи Капри** ([как](#установка-на-свой-компьютер)): запусти установщик или `npm install` и `npm start`.
2. **Подключи нейросеть**: правый клик по Капри › вкладка **ИИ** › выбери, кто будет ей отвечать (Claude по ключу,
   Ollama бесплатно у тебя на ПК, бесплатный облачный Groq/Gemini…) и нажми **Подключить**. Подробно — [ниже](#подключение-нейросети).
3. **Поговори**: клик по Капри › «Поговорить» (или в круговом меню сектор **Говорить**).

Остальное — по желанию: голос, зрение, микрофон, перекраска, руки — всё включается в круговом меню (правый клик по ней).

## Установка на свой компьютер

Капри — приложение на Electron. Лучше всего она работает на **Windows 10/11**: только там она сидит на твоих окнах,
знает, что играет, и умеет управлять окнами и писать в мессенджеры. На macOS и Linux она запускается из исходников
(прозрачному окну нужен композитор), но без этих функций.

### Вариант 1. Готовый установщик (Windows, без командной строки)

Если у тебя есть файл `Capri-Setup-<версия>.exe` — просто запусти его. Установка одним щелчком, в твою учётную запись
(не нужны права администратора), создаётся ярлык на рабочем столе, и Капри сразу появляется. Если установщика нет,
собери его сам (вариант 2, шаг 4).

### Вариант 2. Из исходников (Windows, macOS, Linux)

1. Установи [Node.js](https://nodejs.org) версии **20 или новее** (с галочкой «Add to PATH») и, если хочешь скачивать
   проект командой, [Git](https://git-scm.com).
2. Скачай проект (зелёная кнопка **Code** › **Download ZIP** и распакуй, или в терминале):
   ```bash
   git clone https://github.com/anisimovkirill597-create/capri-desktop-main.git
   cd capri-desktop-main
   git checkout capri-alive
   ```
3. Установи зависимости и запусти:
   ```bash
   npm install
   npm start
   ```
   Капри появится на рабочем столе, а её иконка — у часов (в Windows она иногда прячется за стрелкой ^).
4. **Установщик `.exe`** (по желанию): `npm run dist` — готовый `Capri-Setup-<версия>.exe` появится в папке `dist/`
   (сборка для Windows).

Проверить, что всё в порядке: `npm test` (все тесты должны пройти).

### После установки

- **Правый клик по Капри** — её круговое меню со всеми настройками. **Ctrl+Alt+C** — спрятать её / вернуть.
- **Автозапуск:** меню у часов › «Запускать вместе с Windows».
- **Обновление:** из исходников — `git pull` и `npm install`; установщик — просто запусти новый поверх старого. Твои
  настройки, память и «блокнот о тебе» лежат отдельно (см. ниже) и сохранятся.
- **Где хранятся данные:** папка `%APPDATA%\capri-desktop` (если её нет — рядом ищи `Capri`): `config.json` (настройки;
  ключи там зашифрованы), `memory.json` (память чатов), `bond.json` (что она о тебе узнала). Чтобы начать с чистого листа —
  закрой Капри и удали эту папку.
- **Удаление:** обычным способом через «Приложения и возможности» Windows; данные удаляются вместе с папкой выше.

## Подключение нейросети

Чтобы Капри отвечала в чате, ей нужен «мозг» — нейросеть. Она работает с любой из них, а выбирается и меняется это в
любой момент, без перезапуска:

> **Правый клик по Капри › вкладка «ИИ».** Там видно, подключена ли она сейчас, и можно выбрать другой «мозг».

![Вкладка ИИ в круговом меню: кто ей отвечает, ключ, модель](docs/ai.png)

Если не хочется разбираться самому — нажми там **«Мастер подключения…»**: она сама задаст вопросы кнопками и всё
настроит (поставит Ollama, скачает модель, попросит ключ). То же самое — в меню у часов › «ИИ-модель» › «Выбрать вместе с ней…».

### Что выбрать

| Способ | Для кого | Деньги | Что уходит в интернет |
|---|---|---|---|
| **Claude (API-ключ)** | лучше всего держит её характер и русский | платно, по использованию | сообщения → Anthropic |
| **Claude Code** | у тебя уже есть подписка Claude | по подписке | сообщения → Claude Code → Anthropic |
| **Ollama** | хочешь бесплатно и приватно | бесплатно | ничего |
| **Groq / Gemini** | хочешь бесплатно, без мощного ПК | есть бесплатный тариф | сообщения → сервис |
| **Pollinations** | попробовать за минуту, без аккаунта | бесплатно | сообщения → сервис |
| **LM Studio / llama.cpp / свой сервер** | у тебя уже стоит локальная модель | бесплатно | ничего |
| **OpenAI, OpenRouter, Mistral, DeepSeek** | если уже есть ключ | платно | сообщения → сервис |

### Способ 1. Claude по API-ключу (рекомендую)

Это встроенное подключение к Claude через официальную библиотеку Anthropic. Ответы идут потоком (слова появляются по мере
написания), а список моделей берётся прямо из твоего аккаунта.

1. Зайди на [console.anthropic.com](https://console.anthropic.com), создай аккаунт и пополни баланс (API оплачивается
   отдельно от подписки Claude).
2. Открой **Settings › API Keys** ([прямая ссылка](https://console.anthropic.com/settings/keys)) › **Create Key** и
   скопируй ключ (он начинается с `sk-ant-`; показывается один раз).
3. В Капри: правый клик › вкладка **ИИ** › **«Claude · API-ключ»** › вставь ключ в поле › **Подключить**.
4. Она проверит ключ (запрос к списку моделей) и, если всё хорошо, подключится. Дальше выбери **модель** в этой же вкладке.

**Модели** (цены ориентировочные, за миллион токенов вход/выход; смотри актуальные на сайте Anthropic):

| Модель | Когда брать | Цена |
|---|---|---|
| **Claude Opus 5.5** (по умолчанию) | лучше всех держит характер, самые живые ответы | $4 / $20 |
| **Claude Sonnet 5.5** | дешевле и быстрее, почти не хуже | $2 / $10 |
| **Claude Haiku 5.5** | самая быстрая и дешёвая, для частой болтовни | $0,10 / $0,50 |

Её ответы короткие (1–3 фразы), поэтому на Opus выходит порядка нескольких центов за десяток сообщений, а на Haiku
— копейки. Думать она будет «вполсилы» (низкий уровень рассуждения), чтобы не заставлять тебя ждать.

Что ещё полезно знать:

- Ключ можно не вводить, если он уже есть в системе: переменная окружения `ANTHROPIC_API_KEY` или вход через
  `ant auth login`. Нажми **«Взять из системы»**.
- Если модель по соображениям безопасности откажется отвечать на конкретное сообщение, запрос автоматически уйдёт на
  другую модель (серверный «fallback» Anthropic, включён по умолчанию для Opus/Sonnet 5.5), и Капри не замолчит. Если на
  твоём аккаунте эта функция недоступна, она просто работает без неё.
- Зрение (её «глаза») на Claude тоже работает: включи **Чувства › Видеть мой экран**, и она будет смотреть скриншоты
  той же моделью (можно выбрать дешёвую, например Haiku 5.5, в «Модель зрения…»).
- Ключ хранится **зашифрованным** на этом ПК (учётной записью Windows) и уходит только на серверы Anthropic. Сменить
  или удалить: вкладка ИИ › «Сменить ключ».

### Способ 2. Claude Code (по подписке, без API-ключа)

Если у тебя уже стоит [Claude Code](https://claude.com/claude-code) и ты вошёл в свою подписку, Капри может отвечать
через него — сообщения уходят в `claude -p` (его «безголовый» режим).

1. Установи Claude Code (`npm install -g @anthropic-ai/claude-code`) и один раз запусти `claude`, чтобы войти.
2. В Капри: вкладка **ИИ** › **«Claude Code · по подписке»**.
3. Папка проекта, в которой он работает, и права выбираются в меню у часов › «ИИ-модель». По умолчанию он **только
   читает** (режим `default`); можно разрешить правки без вопросов (`acceptEdits`).

Здесь Капри — просто оболочка над настоящим агентом Claude Code: он может реально работать в твоей папке, а в её пузыре
показывается итог. Блокнот «что она о тебе знает» в этом режиме не ведётся (чтобы не гонять агента ради заметок).

Отдельно, как и раньше, она **следит** за Claude Code / Codex / Antigravity: комментирует, что они делают, и прибегает,
когда нужно твоё разрешение — для этого нужны её «хуки» (меню у часов › «Установить хуки Claude Code», или `npm run hooks:install`).

### Способ 3. Бесплатно и на своём ПК: Ollama

Ничего не уходит в интернет, ключи не нужны. Нужен компьютер с 8 ГБ памяти и больше.

1. Вкладка **ИИ** › **«Мастер подключения…»** › «На этом ПК».
2. Мастер сам установит [Ollama](https://ollama.com) через winget (Windows), запустит её и предложит скачать модель:
   `gemma3:4b` (3,3 ГБ, лучше по-русски) или `llama3.2` (2 ГБ, легче). Скачивание идёт с полосой прогресса.
3. Готово: Капри подключается к `127.0.0.1:11434`.

Для русского языка берут модели покрупнее: `gemma3:4b` и больше. Совсем маленькие (1B) иногда путаются и забывают тег
настроения — тогда она угадывает настроение по тексту.

### Способ 4. Бесплатный облачный тариф

Не нужен мощный компьютер: берёшь бесплатный ключ и вставляешь во вкладке ИИ.

- **Groq** — [console.groq.com/keys](https://console.groq.com/keys) (быстро, хорошо понимает русский);
- **Gemini** — [aistudio.google.com/apikey](https://aistudio.google.com/apikey);
- **OpenRouter** — [openrouter.ai/keys](https://openrouter.ai/keys) (много моделей, часть бесплатные);
- **Pollinations** — вообще без ключа и аккаунта: просто выбери его в списке (можно, чтобы попробовать).

В каждом случае: вкладка ИИ › выбрать сервис › **«Где взять ключ»** (откроет страницу) › вставить ключ › **Подключить**.

### Способ 5. Свой сервер

LM Studio (порт 1234), llama.cpp / vLLM (порт 8080) или любой OpenAI-совместимый адрес: вкладка ИИ › нужный пункт
(для своего адреса — «Свой сервер», впиши, например, `http://127.0.0.1:1234/v1`).

### Проверка связи и ошибки

Во вкладке ИИ сверху видно состояние (**Подключено** — зелёный ромб) и есть кнопка **«Проверить связь»**. Если что-то не так,
Капри скажет это в чате по-человечески:

| Что она говорит | Что делать |
|---|---|
| нет ключа / «Нет связи: no API key» | вставь ключ во вкладке ИИ |
| «Они не принимают этот ключ» | ключ неверный, отозван или с лишним пробелом; создай новый |
| «На счёте у них закончились деньги» | пополни баланс на сайте сервиса |
| «Их серверы перегружены» | подожди минуту; она сама пробует другую модель |
| «Они отказались отвечать на это» | сформулируй иначе |
| «Ollama не отвечает» | запусти «Мастер подключения…» (он поднимет её) |
| не видит Claude Code | проверь, что команда `claude` работает в терминале; перезапусти Капри |

## Настройка

Все настройки — в **круговом меню** (правый клик по Капри). Сектор = вкладка; стрелки переключают вкладки, **Esc** или клик
мимо закрывают. Меню рисуется в цветах её темы, так что перекрасишь её — перекрасится и оно. Те же настройки есть в меню
у часов (иконка Капри рядом с часами; в круговом меню это «Ещё › Системное меню…»).

![Круговое меню: связь и микрофон с живым уровнем](docs/ring.png)

| Вкладка | Что там |
|---|---|
| **Связь** | уровень отношений, четыре «ручки» её поведения, блокнот о тебе, «Забыть всё обо мне» |
| **ИИ** | кто ей отвечает, ключ, модель, «Проверить связь», мастер подключения |
| **Микрофон** | включить, выбрать микрофон, чувствительность, живая волна и уровень, режим «по кнопке» / «разговор» |
| **Чувства** | зрение (видеть экран), танец под музыку, руки (окна и сообщения) |
| **Характер** | эмоции, свои занятия, «знать, что играет», DJ, саморазвитие, бродить по экрану, захватывать окна |
| **Цвета** | 7 тем и «по настроению» |
| **Голос** | как она говорит (молчит / ответы / всё), движок, громкость, **куда идёт звук** (колонки, наушники), проверка |
| **Ещё** | размер, язык, где отдыхает, телепорт, спутник, «Как это работает», «ИИ-модель…», спрятать |
| **Говорить** | открывает чат |

**Горячие клавиши:** **Ctrl+Alt+C** — спрятать/вернуть, **Ctrl+Alt+Space** — говорить с ней голосом (можно сменить в
настройках, ключ `pushToTalk`).

**Где лежат настройки.** Всё это пишется в `config.json` в папке данных. Самое нужное:

| Ключ | Что значит |
|---|---|
| `provider` | кто отвечает: `anthropic`, `claude`, `ollama`, `groq`, `gemini`, `openrouter`, `openai`, `mistral`, `deepseek`, `lmstudio`, `llamacpp`, `pollinations`, `custom` |
| `chatModel`, `visionModel` | модель для чата и для зрения (пусто — первая из доступных) |
| `customUrl` | адрес своего сервера (`provider: custom`) |
| `lang` | язык: `auto`, `ru`, `en`, `fr`, `es`, `pt` |
| `theme`, `scale`, `rest` | цвета, размер (0,45 / 0,6 / 0,8), где отдыхает (`corner` / `taskbar`) |
| `voiceMode`, `ttsEngine`, `audioOut` | голос и устройство вывода |
| `ears`, `converse`, `micDevice`, `micSensitivity`, `sttEngine` | микрофон и распознавание речи |
| `vision`, `rhythm`, `hands`, `learn` | зрение, танец, руки, саморазвитие |

Лучше менять их через меню, а не руками: приложение пишет файл само.

## Что она умеет

### Эмоции

Каждое твоё сообщение в чате что-то с ней делает — **ещё до того, как ИИ ответит**, она реагирует телом. Потом ИИ
получает её текущее настроение и причину («ты назвал её дурой две минуты назад и не извинился») и отвечает в нём.

| Что ты делаешь | Что с ней |
|---|---|
| Оскорбляешь («дура», «заткнись», «ты бесполезная»…) | Злится. Несколько оскорблений подряд — **ярость**: вспышка, красные копии, рык, а потом бьёт молнией по твоему курсору |
| «Ты просто программа», «у тебя нет чувств» | Это её задевает: обида + злость |
| Называешь чужим именем (Алиса, Сири, ChatGPT, Люси…) | «Я КАПРИ.» |
| Грозишь удалить / выключить | Злится и пугается |
| Пишешь капсом | Вздрагивает |
| Повторяешь одно и то же, засыпаешь сообщениями | Раздражается |
| Вспоминаешь Арасаку, Militech, корпов | Фыркает — корпов она ненавидит |
| Смеёшься («ахаха», «лол»), просишь шутку | Хихикает, хохочет над своей же шуткой |
| Делаешь комплимент, «люблю тебя», обнимашки | Смущается: румянец, сердечко, отворачивается |
| Говоришь, что тебе грустно | Становится мягкой, тянется к тебе |
| Спрашиваешь про спутник, звёзды, космос | Мечтательно смотрит на спутник |
| Извиняешься | Остывает. Если была в ярости — одного «прости» мало, нужно два |

И без чата: много кликов подряд — «эй, хватит», потом взрыв; курсор туда-сюда по ней — щекотно; курсор у неё на голове — это
поглаживание; таскаешь её — кружится голова; долго не обращаешь внимания — скучает и находит себе занятие.
Злость остывает сама за несколько минут, но **обиду она помнит даже после перезапуска**. Настроение видно на панели
(◆ ЗЛИТСЯ, ◆ СМУЩЕНА…). Выключить: **Характер › Эмоции**.

### Голос

**Голос › Как она говорит:** молчит, озвучивает ответы чата или озвучивает всё. Движки:

- **Системный** — бесплатно и без интернета, голоса Windows (по-русски Irina / Svetlana, если стоит русский языковой пакет).
  Высота и темп меняются от настроения: злая — ниже и быстрее, смущённая — выше.
- **OpenAI** — нужен ключ OpenAI. Модель `gpt-4o-mini-tts` получает инструкцию, *как* говорить («зло, сквозь рык»).
- **ElevenLabs** — твой ключ и ID голоса из твоей библиотеки; с моделью `eleven_v3` настроение передаётся тегами.
- **Свой сервер** — любой, совместимый с OpenAI `/v1/audio/speech`, например [Kokoro-FastAPI](https://github.com/remsky/Kokoro-FastAPI)
  у тебя на ПК (`http://127.0.0.1:8880/v1`): бесплатно и офлайн.

К облачному голосу подмешивается эффект «множества разумов» (две запаздывающие «плавающие» копии и цифровой оттенок).
**Куда идёт звук:** там же выбираешь колонки или наушники (её блипы, звуки и голос облачных сервисов идут на выбранное
устройство; системный голос Windows всегда звучит на устройстве по умолчанию), есть проверочный звук и
**«Слышать свой микрофон»** — проверить микрофон на выбранном устройстве (микрофон открыт, а значок мигает, только пока
вкладка на экране; лучше в наушниках, с колонками может свистеть).

> Не клонируй голос реальной актрисы без её разрешения. Подбери похожий голос из библиотеки или любой, который нравится.

### Цвет

![Её цвета](docs/themes.png)

Красный (как в аниме), нетраннер (циан), токсичный (кислотно-зелёный), фиолетовый, золото, сакура (розовый), призрак
(белый) — и **по настроению** (злая — красная, грустная — синяя, смущённая — розовая, весёлая — золотая, скучающая —
белая). Меняется всё: грива, цветная «тень», панели, молнии, осколки и само круговое меню. В чате тоже можно:
«перекрасься в синий», «стань розовой», «верни как было», «перекрасься под настроение».

### Своя жизнь

![Чем она занята](docs/life.png)

Когда ничего не происходит, она находит, чем заняться, и пишет это в бегущей строке над головой: **взламывает лёд**
Арасаки / Militech / Biotechnica (удалось — радуется, сработал чёрный лёд — её отбрасывает), играет в **аркаду** (и
бесится, проиграв), читает **дата-шарды**, рисует **граффити** прямо на экране, **сканирует сеть**, спорит с другими
разумами внутри себя, потягивается.

**Музыка** (Windows): она знает, что играет (название и исполнитель; Spotify, браузер, Яндекс Музыка, AIMP… всё, что
сообщает Windows), надевает наушники и качает головой в такт, иногда высказывает мнение. В **режиме DJ** сама переключает
трек, когда ей надоело (не чаще раза в 20–35 минут и никогда не тот, что ты только что включил); в тишине предложит что-нибудь включить.
**Ты:** встретит, если тебя не было больше 5 минут, поздоровается утром, после часа ночи скажет, что пора спать, при
батарее ниже 15% пожалуется на холод. Отключается в **Характер**.

### Чувства: зрение, слух, танец

Всё это **выключено по умолчанию**: каждое — доступ к экрану, звуку или микрофону, поэтому включается вручную
(вкладки **Чувства** и **Микрофон**), а пока оно включено, внизу слева горит значок (◉ ВИЖУ, ● MIC), чтобы ни один
«датчик» не работал втихую.

![Видит экран и пишет сообщение с подтверждением](docs/senses.png)

- **Зрение.** Время от времени (и по просьбе «посмотри на экран», «что у меня на экране?») она делает маленький снимок
  экрана, показывает его модели зрения и реагирует в своём стиле. Перед снимком прячет саму себя; снимок **нигде не
  сохраняется** и уходит только в выбранную модель. Работает с Claude (Opus/Sonnet/Haiku), локальными `qwen2.5vl` / `llava`
  в Ollama и облачными `gpt-4o-mini`, Gemini, Llama-4-Scout.
- **Танец под музыку.** Она слушает **реальный звук системы**, ловит бит по басу и качается, машет гривой и крутится в
  такт (громче — шире). Только громкость и ритм: ни названий, ни записи.
- **Слух и голос.** Жми **Ctrl+Alt+Space** (или кнопку микрофона) и говори — она запишет, распознает речь и ответит; если
  включён голос, **вслух**, так что можно общаться совсем без рук. **Режим разговора** — микрофон остаётся открытым, вы
  говорите по очереди. Распознавание: **Groq** (бесплатный тариф, хорошо понимает русский), **OpenAI** или свой сервер
  (whisper.cpp / faster-whisper). Выбрать: **Микрофон › Распознавание речи…**. Вкладка **Микрофон** показывает, что она
  слышит: живую волну и уровень, линию «отсюда начинается голос» и устройство, которое можно сменить на лету.

### Руки: окна и сообщения (Windows)

Выключено по умолчанию: вкладка **Чувства › Работать с окнами**. Тогда в чате (и голосом) можно:

- **Окна:** «сверни окно хрома», «разверни телеграм», «переключись на VS Code», «покажи рабочий стол». Делает сразу.
- **Сообщения** (если включено «Писать сообщения»): «капри, открой телеграм и напиши маме, скоро буду дома», «напиши в
  дискорде каналу general: тест». Она откроет приложение, найдёт чат и **наберёт сообщение, но не отправит**: сначала
  покажет **кому** и **что**, и кнопку «Отправить». Отправит только после клика. Если во время набора на передний план
  выскочит другое окно, она **остановится**, а не напишет не туда. Текст идёт через буфер обмена, и он возвращается как был.

Поддерживаются **Telegram, Discord, WhatsApp, Slack** (десктоп-версии, стандартные горячие клавиши поиска). Она никогда не
трогает окна самой Капри, Claude и Ollama.

### Саморазвитие: она узнаёт тебя

Включено по умолчанию (**Характер › Узнаёт меня**), всё хранится только на твоём ПК (`bond.json`).

![Она становится ближе и помнит, кто ты](docs/bond.png)

- **Как ты пишешь** — длина сообщений, смайлы, мат, «ты» или «вы», в какие часы ты тут. Только счётчики, сами сообщения не
  хранятся. Пишешь коротко — отвечает коротко; материшься по привычке (не на неё) — перестаёт фыркать.
- **Как ты принимаешь её ответы** — посмеялся, «спасибо», «круто» — она чуть больше в эту сторону; «бред», «скучно» — в
  обратную. Прямые просьбы работают сразу и навсегда: «давай покороче», «а подробнее?», «без сленга», «не шути».
- **Что ты о себе рассказываешь** — каждые несколько сообщений (и при закрытии чата) её же нейросеть делает записи в
  блокнот: чем занимаешься, что любишь и не любишь. Пароли, телефоны, адреса, номера карт, здоровье и деньги туда не
  попадают. С Claude Code в роли чата блокнот не ведётся.

Чем дольше вместе, тем ближе: **незнакомцы → знакомимся → друзья → близкие → один из нас** — и она говорит с тобой
по-другому (но грубишь постоянно — близко не подпустит). Вкладка **Связь** показывает уровень, прогресс, блокнот (можно
убирать записи и добавлять свои) и четыре «ручки» поведения. Спроси в чате «**что ты обо мне знаешь?**» или скажи
«**забудь всё обо мне**».

### Сон и ресурсы

Когда её не зовут, она засыпает (остаётся маска) или ты прячешь её в чип (**Ctrl+Alt+C**) — и переходит в лёгкий режим:
рисуется по таймеру и только когда что-то меняется (несколько кадров в секунду вместо 60–144), останавливает фоновые
процессы слежения за окнами и музыкой, реже проверяет, у компьютера ли ты, усыпляет звук. В нашем замере работа окна во
сне упала в 4–5 раз. Проснётся мгновенно: клик, Claude, меню или шорткат.

**Обновления тоже экономные:** изменение настройки, которое ничего не меняет, не делает ничего; частые изменения (ползунок
в меню) пишутся в файл один раз; меню у часов перестраивается не чаще раза в 0,12 с; кусочки ответа идут пачками;
список моделей облачного сервиса запоминается на минуту. Из установщика убрано всё лишнее (шрифты — только нужные).

### Она следит за твоим ИИ для кода

Подключи её к Claude Code / Codex / Antigravity (меню у часов › «Установить хуки Claude Code», или `npm run hooks:install`): она
телепортируется к твоему окну, комментирует каждое действие, прибегает, когда нужно твоё разрешение, и радуется (или
ругается), когда работа сделана. Отчёт о миссии — в меню. Без хуков тоже работает всё, кроме слежения.

## Если что-то не работает

- **Фон у неё чёрный (не прозрачный).** Меню у часов › «Отображение» › «OpenGL (если её фон чёрный)», а если не помогло — «Без видеокарты». Она
  перезапустится.
- **Она молчит / «нет связи».** Вкладка **ИИ › Проверить связь** покажет причину; таблица ошибок — [выше](#проверка-связи-и-ошибки).
- **Нет звука голоса.** Вкладка **Голос**: не стоит ли «Молчит», «Без звука» и верное ли устройство; кнопка «Проверить звук».
- **Микрофон не открывается.** Windows › Параметры › Конфиденциальность › Микрофон: разреши классическим приложениям;
  вкладка **Микрофон** › «Ещё раз».
- **Она не сидит на окнах, не знает музыку, не управляет окнами.** Эти функции только для Windows.
- **Где она?** Если ты её спрятал, **Ctrl+Alt+C** или меню у часов › «Вернуть её».
- **Начать с нуля.** Закрой Капри и удали папку данных (`%APPDATA%\capri-desktop`).

## Что уходит с твоего ПК

- Твои сообщения — только в выбранную тобой нейросеть (при локальной — никуда; при Claude — на серверы Anthropic).
- Текст для озвучки — только в выбранный голосовой сервис (системный голос и свой сервер — никуда).
- Что играет — читается локально и попадает только в подсказку твоей же нейросети, чтобы Капри могла это обсудить.
- **Снимок экрана** (если включено зрение) — только в выбранную модель зрения, нигде не сохраняется.
- **Твой голос** (если включён микрофон) — только в выбранный сервис распознавания, запись не хранится. Вкладка Микрофон и
  «Слышать свой микрофон» держат микрофон открытым, только пока открыты, а значок это показывает.
- **Звук системы для танца** — обрабатывается локально (громкость и ритм), не записывается и не отправляется.
- Её настроение, обиды, занятия и «блокнот о тебе» — только в папке данных на ПК. Записи в блокнот делает та же нейросеть, с
  которой ты общаешься.
- **API-ключи** хранятся зашифрованными (учётной записью Windows) и отправляются только в тот сервис, которому принадлежат.
